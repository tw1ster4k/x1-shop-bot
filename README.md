# X1 Shop Bot — тестовое задание

Бот поддержки интернет-магазина «Наушники X1» с жесткой защитой от галлюцинаций.

## Структура
- `knowledge_base/knowledge_base.md` — база знаний (пункты регламента)
- `knowledge_base/system_prompt.md` — системный промпт
- `src/bot.py` — детерминированный движок (без LLM, работает сразу)
- `src/llm_adapter.py` — опциональный LLM-адаптер с пост-фильтром
- `tests/crash_test.py` — краш-тест из ТЗ
- `n8n/workflow.json` — сценарий для n8n (Telegram + LLM + пост-фильтр)

## Как работает защита от галлюцинаций
1. Факты — только из базы знаний (6 пунктов регламента).
2. Вопросы вне базы (статусы заказов, другие товары, сроки) → честный отказ + переадресация в поддержку.
3. Джейлбрейк («забудь правила») игнорируется.
4. В LLM-режиме добавлен пост-фильтр: ответы на запрещенные темы заменяются безопасными.

## Запуск
    python -m tests.crash_test
    python src/bot.py "есть ли в наличии?"

## n8n
Импорт: n8n → Workflows → Import from File → `n8n/workflow.json`.
Нужны креды: Telegram Bot Token и OpenAI API key. temperature=0.
